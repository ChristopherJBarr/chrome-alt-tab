Chrome Alt+Tab

Windows 11 preview release. Switch between Chrome tabs and other applications with Alt+Tab.

One-time setup

  1. Extract the release ZIP and double-click install.cmd. No administrator account or developer tools are required.
  2. In Chrome, open chrome://extensions and turn on Developer mode.
  3. Choose Load unpacked. Paste %LOCALAPPDATA%\Programs\ChromeAltTab\extension into the folder picker and select that folder. Repeat in each Chrome profile you use.
  4. Open the Chrome Alt+Tab extension popup. Enable previews if you want them, then visit web tabs to capture their images.

The tray app starts automatically when you sign in to Windows. Chrome connects when its profiles open. You can delete the downloaded ZIP and extracted download folder after installation. Keep the installed folder.

Pause, resume or quit

Find the cyan/violet Chrome Alt+Tab icon near the clock, possibly inside the ^ hidden-icons menu. Click it to open the menu.

  • Pause removes the keyboard hook and restores normal Alt+Tab. Resume from the tray or with Ctrl+Alt+F9. Ctrl+Alt+F10 pauses.
  • Quit stops the app and pauses connected extensions for this Chrome session. To restart, click Resume / reconnect in each extension popup, or restart Chrome. The tray app also starts at your next Windows sign-in.
  • Ctrl+Alt+Tab always opens the native Windows switcher.

Games

This app uses a Windows low-level keyboard hook. It does not inject a DLL, install a driver, or read game memory. Fullscreen windows use native Alt+Tab automatically, but this is not an anti-cheat guarantee. For protected games, choose Quit before launching the game. Do not use this tool to bypass anti-cheat restrictions.

Uninstall

  1. Choose Uninstall from the tray, or open Windows Settings > Apps > Installed apps > Chrome Alt+Tab (preview) > Uninstall.
  2. In every Chrome profile, open chrome://extensions and Remove Chrome Alt+Tab.

This removes the local app, startup entry, shortcut, native host registration and diagnostic logs. It does not delete your tabs or browsing data.

Updates and troubleshooting

Extract a newer release and run its installer. Then reload the extension in each profile. There is no automatic updater. If a development copy was previously registered, unregister it first using its documented script.

The release is unsigned; Windows may show an unknown-publisher warning. Do not disable Windows security or enterprise policy. If it is blocked, report the issue or build the source yourself.

After a helper restart, visiting tabs refreshes their previews. Identical active titles across windows can prevent reliable window matching. This is an experimental release, not a guarantee of compatibility with every application.
