# Security

This project is experimental and has no supported stable release yet. It runs with the current user's permissions and installs a local keyboard hook for switching. The optional Chrome preview permission permits capture of visible web pages; enable it only if comfortable with that access.

Please avoid posting exploitable vulnerabilities or private browsing information in public issues. If the hosting repository offers private vulnerability reporting, use that channel. Otherwise contact a maintainer privately before disclosing details. Do not include credentials or real page captures in reports.

Same-user malicious software, elevated application control, security desktops and enterprise policy bypasses are outside the intended trust boundary. No administrator elevation is needed for ordinary operation.
